주요 기능

🏠

서버 Room 생성

동적으로 서버 Room을 생성하고 설정을 관리할 수 있습니다.

socket.emit('createRoom', {...})
📋

서버 Room 목록 조회

서버에 존재하는 모든 Room 목록을 조회할 수 있습니다.

socket.emit('rooms', callback)
🚪

서버 Room 입장

서버 Room에 입장하여 실시간 통신에 참여할 수 있습니다.

socket.emit('joinRoom', {...})
💬

실시간 메시지

서버 Room 내 모든 클라이언트에게 실시간으로 데이터를 전송할 수 있습니다.

socket.emit('message', 'data')
👥

멤버 관리

서버 Room별 연결된 클라이언트 목록을 실시간으로 관리하고 조회할 수 있습니다.

socket.on('members', callback)
📝

서버 Room 정보 조회

서버 Room의 상세 정보와 현재 상태를 조회할 수 있습니다.

socket.emit('roomInfo', roomId)
🧹

서버 Room 정리

관리자 권한으로 모든 서버 Room을 정리하고 초기화할 수 있습니다.

socket.emit('cleanRooms')

사용 방법

사용 가능한 네임스페이스

다음 네임스페이스에 연결하여 웹소켓 서비스를 이용할 수 있습니다.(실제 개발시에는 sample 대신 부여받은 client-id 입력)

  • /ws/sample - 샘플 네임스페이스

1. Socket.io 클라이언트 연결

// Socket.io 라이브러리 로드
<script src="https://cdn.socket.io/4.5.0/socket.io.min.js"></script>

// 네임스페이스에 연결
const socket = io('<%= apiUrl %>/ws/sample');

// 연결 상태 확인
socket.on('connect', () => {
  console.log('서버에 연결되었습니다:', socket.id);
});

2. 서버 Room 생성

// 서버 Room 생성
socket.emit('createRoom', {
  roomId: 'my-room-123',        // 선택사항: 서버 Room ID (없으면 자동생성)
  user_id: 'user123',           // 호스트 사용자 ID
  hostName: '홍길동',            // 호스트 이름
  roomName: '내 서버 Room',      // 필수: 서버 Room 이름
  capacity: 10,                 // 선택사항: 최대 인원 (기본값: 99)
  autoClose: true              // 선택사항: 빈 서버 Room 자동 삭제 (기본값: false)
}, (response) => {
  if (response.ok) {
    console.log('서버 Room 생성 성공:', response.roomInfo);
  } else {
    console.log('서버 Room 생성 실패:', response.message);
  }
});

3. 서버 Room 입장

// 서버 Room 입장
socket.emit('joinRoom', {
  roomId: 'my-room-123',        // 필수: 입장할 서버 Room ID
  user_id: 'user456',           // 필수: 사용자 ID
  nickName: '김철수'            // 선택사항: 닉네임 (없으면 '게스트N')
}, (response) => {
  if (response.ok) {
    console.log('서버 Room 입장 성공:', response.roomInfo);
  } else {
    console.log('서버 Room 입장 실패:', response.message);
  }
});
// 또는, 예제 UI에서 Room 목록의 '입장' 버튼을 눌러 바로 입장할 수 있습니다.

4. 데이터 송수신

// 데이터 전송
socket.emit('message', '안녕하세요! 데이터를 전송합니다.');

// 데이터 수신
socket.on('message', (data) => {
  console.log(`${data.nickName}: ${data.msg}`);
  console.log('시간:', data.timestamp);
  
  // 시스템 메시지인 경우 data.msg는 객체일 수 있음
  if (typeof data.msg === 'object') {
    console.log('액션:', data.msg.action);
    console.log('내용:', data.msg.msg);
  }
});

5. 멤버 및 룸 정보 관리

// 멤버 목록 변경 알림 수신
socket.on('members', (memberList) => {
  console.log('현재 멤버:', memberList);
  // memberList = { user_id: { nickName, joinTime }, ... }
});

// 서버 Room 목록 변경 알림 수신
socket.on('rooms', (roomList) => {
  console.log('현재 서버 Room 목록:', roomList);
});

// 특정 서버 Room 정보 조회
socket.emit('roomInfo', 'my-room-123', (roomInfo) => {
  console.log('서버 Room 정보:', roomInfo);
});

// 전체 서버 Room 목록 조회
socket.emit('rooms', (roomList) => {
  console.log('서버 Room 목록:', roomList);
});

6. 서버 Room 나가기 및 정리

// 서버 Room 나가기
socket.emit('leaveRoom');

// 연결 해제 (자동으로 서버 Room에서 나가짐)
socket.disconnect();

// 모든 서버 Room 정리 (관리자 기능)
socket.emit('cleanRooms');

7. 완전한 클라이언트 예제

<!DOCTYPE html>
<html>
<head>
    <title>WebSocket Example</title>
    <script src="https://cdn.socket.io/4.5.0/socket.io.min.js"></script>
</head>
<body>
    <div id="messages"></div>
    <input type="text" id="messageInput" placeholder="데이터를 입력하세요...">
    <button onclick="sendMessage()">전송</button>

    <script>
        const socket = io('<%= apiUrl %>/ws/sample');
        
        // 룸 생성 후 입장
        socket.emit('createRoom', {
            roomName: '테스트 서버 Room',
            user_id: 'test-user',
            hostName: '테스터'
        }, (response) => {
            if (response.ok) {
                socket.emit('joinRoom', {
                    roomId: response.roomInfo.roomId,
                    user_id: 'test-user',
                    nickName: '테스터'
                });
            }
        });
        
        // 데이터 수신 처리
        socket.on('message', (data) => {
            const messages = document.getElementById('messages');
            messages.innerHTML += `<div><strong>${data.nickName}:</strong> ${data.msg}</div>`;
        });
        
        // 데이터 전송 함수
        function sendMessage() {
            const input = document.getElementById('messageInput');
            if (input.value.trim()) {
                socket.emit('message', input.value);
                input.value = '';
            }
        }
        
        // 엔터키로 데이터 전송
        document.getElementById('messageInput').addEventListener('keypress', (e) => {
            if (e.key === 'Enter') sendMessage();
        });
    </script>
</body>
</html>

변경 사항

v1.4.0 - 2025.07.29

  • [기능 추가] 일반 이메일 전송 기능 추가
    • 회원 가입 축하, 배송 상태 변경 등 일반적인 정보를 제공하는 목적의 이메일을 보내고 싶을 때 사용합니다.
    • 이메일을 통한 인증을 원한다면 인증 이메일 전송 API를 사용하세요.
    • API 문서 보기: 일반 이메일 전송
  • [기능 추가] 인증 이메일 전송 기능 추가
    • 이메일 인증 서비스는 지정한 사용자에게 인증 링크가 있는 이메일을 보내고 인증이 완료되면 회원 정보에 인증 정보를 추가하므로 회원 가입을 완료한 후에 요청해야 합니다.
    • 회원 가입시 extra.emailConfirm 속성을 false로 지정하면 이메일을 인증하지 않은 사용자는 로그인을 할 수 없습니다.
    • 이메일에 전달되는 "인증 완료" 버튼을 클릭하면 이메일을 인증한 후 extra.emailConfirm 속성을 true로 변경하고 인증 완료 페이지로 이동합니다.
    • 이 모든 작업은 API 서버에서 처리되므로 이메일 인증을 하고 싶은 팀은 "회원 가입" 후에 "인증 이메일 전송"을 요청만하면 됩니다.
    • 만약 회원 가입 도중에 이메일 인증을 먼저 하고 싶다면 자체적으로 인증 코드를 생성한 후 일반 이메일 전송을 요청해서 이메일 본문에 인증 코드를 보내고 사용자가 인증 코드를 입력하면 자체적으로 검증하도록 구현하면 됩니다.
    • API 문서 보기: 인증 이메일 전송

v1.2.0 - 2025.07.28

  • [기능 수정] 북마크 목록 조회시 응답 데이터에 user_id 속성 추가
    • 변경전: { "ok": 1, "item": [ { "_id": 1, "memo": "첫째 크리스마스 선물.", ... }, ... ] }
    • 변경후: { "ok": 1, "item": [ { "_id": 1, "user_id": 4, "memo": "첫째 크리스마스 선물.", ... }, ... ] }
    • API 문서 보기: 북마크 목록 조회
  • [버그 수정] 북마크 목록 조회시 응답 데이터 포맷이 API 문서와 다르게 나오던 문제 수정
    • 변경전: { "0": { ... }, "1": { ... }, "2": { ... }, "ok": 1 }
    • 변경후: { "ok": 1, "item": [ { ... }, { ... }, { ... } ] }
    • API 문서 보기: 북마크 목록 조회

주요 기능

🛒

상품 관리

상품 등록, 수정, 삭제 및 카테고리별 조회 기능을 제공합니다.

GET /market/products
👤

회원 인증

회원가입, 로그인, 프로필 관리, 카카오/구글/깃허브 로그인을 제공합니다.

POST /market/auth/login
📦

주문 관리

주문 생성, 조회, 상태 변경, 배송 관리 기능을 제공합니다.

POST /market/orders
🛍️

장바구니

장바구니 상품 추가, 삭제, 수량 변경 기능을 제공합니다.

POST /market/carts
❤️

북마크(찜하기)

상품, 사용자, 게시글에 대한 북마크 관리 기능을 제공합니다.

POST /market/bookmarks
⭐

구매 후기

상품 구매 후기 작성, 조회, 관리 기능을 제공합니다.

POST /market/orders/:_id/products/:product_id/replies
💬

게시판

QnA, 공지사항 등 다양한 게시판 기능을 제공합니다.

GET /market/posts
📊

통계 조회

판매자별, 상품별, 일별 매출 및 주문 통계를 제공합니다.

GET /market/admin/orders/statics
📁

파일 관리

상품 이미지, 프로필 사진 등 파일 업로드 기능을 제공합니다.

POST /market/files
🔔

알림 메시지

주문, QnA 등에 대한 실시간 알림 기능을 제공합니다.

GET /market/notifications
